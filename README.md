- **🔘 True Neumorphism (Soft UI) Design System**:

- **⚡ Zero-Database Architecture**:
  - Completely static and type-safe data architecture (`lib/data/`).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment (Optional)
If you wish to use live Google Gemini AI, copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```
Add your free Google Gemini API key from [Google AI Studio](https://aistudio.google.com/):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: If no key is set, the Copilot automatically uses high-precision grounded responses!)*

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### 4. Build for Production
```bash
npm run build
npm run start
```
